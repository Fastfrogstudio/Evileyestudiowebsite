# Showcase drop folders

Drop studio showcase assets here and they get wired into the
Art / Animation sliders on studio.html (js/studio-assets.js).

- `art/`       — stills: key art, characters, symbols, environments (png/jpg/webp)
- `animation/` — motion: gif / animated webp clips

Wide/landscape files look best (the slider frame is 16:9).
Filenames become captions (e.g. `rat-attack-boss-reveal.png`
→ "Rat Attack Boss Reveal"), so name them descriptively.
